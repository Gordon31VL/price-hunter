# Best Mirage Prices Bot

Discord-бот на Node.js, который читает сообщения со списками цен скупщиков и отвечает красивой сводкой с лучшей ценой каждого товара. Для сравнения используется цена до скобок; значение в скобках показывается рядом для справки.

## Требования

- Node.js 20 или новее
- Discord-приложение и бот
- Включённый **Message Content Intent** в Discord Developer Portal

## Установка и запуск

1. Установите зависимости: `npm install`.
2. Скопируйте `.env.example` в `.env` и задайте `DISCORD_TOKEN` и `DISCORD_CLIENT_ID`.
3. Включите **Message Content Intent** в настройках бота в Discord Developer Portal и пригласите бота на сервер с правами читать сообщения и отправлять сообщения/встраивания.
4. Зарегистрируйте команду: `npm run deploy-commands`.
5. Запустите бота: `npm start`.

Для разработки и проверки парсера запустите `npm test`.

## Команды

- `/channel set` — выбрать канал для обработки сообщений (требуется право «Управление сервером»).
- `/channel show` — посмотреть выбранный канал.
- `/notify-role set` — выбрать роль, которую бот упоминает при публикации цен и выдаёт по реакции 🔔 (требуется право «Управление сервером»).
- `/notify-role show` — посмотреть выбранную роль уведомлений.
- `/notify-role clear` — отключить упоминание роли.
- `/range set` — выбрать товар и задать включённые минимальную и максимальную цену.
- `/range list` — посмотреть все установленные на сервере диапазоны.
- `/range clear` — удалить диапазон выбранного товара.

Бот показывает все предложения скупщиков, у которых цена товара попадает в настроенный диапазон включительно. Если все цены товара ниже минимума или выше максимума, товар пропускается. Товары сортируются по названию, а предложения для каждого товара — по убыванию цены. Диапазоны сохраняются в `data/ranges.json` отдельно для каждого сервера и переживают перезапуск.

## Обработка сообщений

Сначала используйте `/channel set` и выберите текстовый канал. Бот распознаёт там разделы с заголовками вида `Скупщик сырья №1` и `Скупщик продуктов`, а также строки вида `- Медь: $29 ($34)`, после чего отправляет сводку в тот же канал. В остальных каналах сообщения и команды диапазонов не обрабатываются. Команда `/channel` нужна для настройки и просмотра канала и доступна участникам с правом «Управление сервером». Выбранный канал сохраняется отдельно для каждого сервера в `data/ranges.json`.

Для упоминания при публикации сводки администратор может выбрать роль командой `/notify-role set`. Пользователь может нажать 🔔 под любой сводкой бота, чтобы получить эту роль; снятие своей реакции убирает роль. Настройка хранится отдельно на каждом сервере. Роль должна находиться ниже высшей роли бота, а у бота должно быть право «Управление ролями» и право добавлять реакции в выбранном канале. Чтобы участники получали уведомления от упоминания, роль необходимо сделать упоминаемой в настройках Discord либо выдать боту разрешение «Упоминать @everyone, @here и все роли». Бот отправляет только явно выбранное упоминание и не упоминает эту роль в ответном сообщении на настройку.
